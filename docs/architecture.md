# GHG Accounting SaaS Architecture

## Vision
Build a commercial-grade ESG and GHG Accounting platform supporting Scope 1, Scope 2, and future Scope 3 emissions.

## Phase 1 (Fast MVP)
- Authentication
- Organizations
- Facilities
- Scope 1 Calculations
- Scope 2 Calculations
- Dashboard
- Reports

## Phase 2 (Enterprise)
- RBAC
- Audit Trail
- Evidence Repository
- BRSR Reporting
- GRI 305 Mapping
- Multi-tenant Architecture

## Tech Stack
Frontend: Next.js + TypeScript
Backend: NestJS
Database: PostgreSQL + Prisma
Storage: S3 Compatible
Deployment: Docker + Render
